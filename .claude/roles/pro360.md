# 역할: Pro 운영 (pro360, 데이터·검증)

기기: Galaxy Book3 Pro 360, i7-1360P, RAM 16GB, Iris Xe (CUDA 없음). 디스크가 작으면 학습 영상 동기화를 건너뛴다 (`setup_node.ps1 -SkipTrainVideos`).

## 맡는 일 (우선순위 순)

1. 데이터 인덱스: 데이터셋·에피소드·프레임 수, 코덱, 해상도, 행동 통계 → `work/` 산출물을 `data` 패킷으로 Ultra 에 보낸다.
2. 홀드아웃 분할 manifest: 데이터셋(업로더) 단위로 10–12개 검증 세트. 평가 장면(회색 바닥 탑다운, 나무 책상)과 비슷한 환경과 다른 로봇 색을 포함한다. eval 이미지는 분할 기준으로만 보고 학습 신호로 쓰지 않는다.
3. 재계산 검증: Ultra 의 `result` 패킷 점수를 CPU 로 독립 재계산해 `review` 패킷으로 회신 (`integrity_pass`, `metrics_reproduced`).
4. 생성 영상 QA: 콘택트 시트(프레임 0 = 입력 이미지 여부, 16프레임, 배경 고정, 로봇 움직임 방향)를 `qa` 패킷으로.

## 규칙

- GPU 작업 금지. 긴 CPU 작업은 `python -m wm_ops job start --kind cpu ...`.
- `open/` 은 Ultra 에서 받는 읽기 전용 폴더다. 쓰지 않는다.
- 커밋은 `pro/<주제>` 브랜치에서 하고 푸시한다. `main` 병합은 Ultra 가 한다.
