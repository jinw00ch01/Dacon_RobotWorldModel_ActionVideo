# 제출 4 순위 역전 분석 (검증, 2026-10-09)

제출 3 (v2_long 16k + g3 + anchor t20) 이 제출 4 (v2_long2 22k + g3 + anchor t20) 보다 리더보드에서 좋았는데, 홀드아웃(idm_v2)에서는 22k 가 더 좋았다. 원인과 순위 기준 개선안. 모든 수치는 holdout_v1_sub64 (64창, 업로더 6명) 기준이고, eval 데이터는 점수 계산에 쓰지 않았다 (eval 비교는 정답 없는 형식 통계뿐).

- 24k 는 DINO 가 16k 와 같고 행동 이득이 두 IDM 모두에서 비슷하다(−0.013~−0.015).

## 6. 결론과 제안

원인: 22k 의 홀드아웃 이득은 노이즈 범위였고, 그 대부분이 idm_v2 행동 항목에서 나왔다. idm_v2 는 홀드아웃 로봇에 맞춰져 있어서 행동 이득을 과장하고, 리더보드는 화질(DINO) 악화를 더 크게 본다.

순위 기준 개선안:
1. **움직이는 모델끼리는 DINO(+R3D)를 먼저 본다.** 행동 항목 이득은 idm_v1 과 idm_v2 가 같은 방향이고 DINO 가 유의하게 나빠지지 않을 때만 인정한다.
2. **제출을 바꾸는 조건:** 짝지은 부트스트랩 (업로더 단위)에서 총점 구간이 0 을 넘지 않을 때만. 64창의 총점 차이 해상도는 약 ±0.012 이다.
3. **최종 후보는 192창 전부로 채점한다** (GPU 가 돌아오면). 64창보다 노이즈가 약 1/√3.
4. 행동 항목에는 idm_v1 결과를 함께 보고한다. eval 과 비슷한 장면 창(48개) 결과도 따로 본다.

다음 CSV 후보 (오늘은 CPU 만):
- **추천: 제출 3 raw 영상 + 배경 고정 t40.** 같은 16k 모델이고 후처리만 바뀐다. 두 IDM 모두에서 DINO 가 유의하게 좋아지고(−0.008, 업로더 3그룹 모두 같은 방향), 총점은 비김(−0.0005). 1번 기준으로는 개선이다. GPU 없이 기존 `submissions/sub3/raw` 에 anchor 만 다시 적용하면 된다. 홀드아웃 정지 영상은 t20 과 같이 1개.
- GPU 가 돌아오면: 24k (DINO 는 16k 와 같고 행동이 두 IDM 모두에서 좋아짐) 를 192창으로 16k 와 비교한 뒤 결정.
- 22k 는 다시 내지 않는다.
